# Соц сеть (публикация фотографий)

Веб-приложение на базе Spring Boot. Включает ролевую модель доступа, валидацию данных и контейнеризацию.

## 🚀 Технологический стек
* **JDK:** Java 21
* **Spring:** Spring Boot 4.1.0 (Web, Data JPA, Security)
* **DB:** PostgreSQL 16
* **Инструмент сборки:** Maven 3.9.11
* **Контейнеризация:** Docker, Docker Compose
* **Контроль версий:** Git 2.55.0
